## Agent Brief

**Category:** bug
**Summary:** In an Interconnection Diagram, each wire (connection, interface, flow, binding) must be traceable on its own: no shared segments with other wires, no labels on top of each other, and no passing through a box that isn't one of its ends.

**Current behavior:**
Wires leaving or entering nearby ports are routed onto the same horizontal or vertical segment, so several wires look like one line. Their name labels are placed near the same point and overlap. Two flows in opposite directions between the same pair of ports end in arrowheads that meet in the middle. A wire can be routed straight through an unrelated box.

**Desired behavior:**
- **Separate tracks:** two different wires never share a segment of their route; parallel wires run side by side with visible separation.
- **Labels:** wire labels don't overlap each other, a box, or a port label.
- **Arrowheads:** each flow's arrowhead sits at its own target end, so two opposing flows between the same ports read as two arrows, not a bow-tie.
- **Boxes:** a wire never passes through the interior of a box other than the boxes it starts or ends in, and those boxes' ancestors (a Frame or Opened Part it is inside).

Bend points the user set in the Layout are still honoured as they are today.

**Key interfaces:**
- Interconnection Diagram edge routing and wire label placement.
- Existing routing tests and interconnection golden SVGs, which will change.

**Acceptance criteria:**
- [ ] A test: two flows in opposite directions between the same two ports are drawn as two distinct routes with non-overlapping labels.
- [ ] A test: three wires leaving neighbouring ports of one box toward a second box share no segment.
- [ ] A test: a wire whose straight route would cross a third box is routed around it.
- [ ] bike-radar-model `rideContext` and `internalStructure` (commit `b6a3056`): every wire can be followed from end to end, no wire labels overlap, and `ledSupply` doesn't cross `battery`.
- [ ] User-set bend points in a Diagram File are still honoured.

- Port labels: [04](04-layouts-hard-to-read.md).
- Edge routing in tree and General Diagrams: [10](10-wide-trees.md).
