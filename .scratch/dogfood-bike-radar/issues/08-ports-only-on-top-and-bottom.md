# 08: Undirected ports are only ever placed on the top or bottom edge

**Status:** needs-triage

**Category:** enhancement

## Seen

Every port sits on a box's top or bottom edge, never its sides, even when the box has room there. Wires therefore detour around boxes (`mcuSupply`, `radarSupply`, `cellVoltage`), and the picture is tall and mostly empty (`internalStructure` is 995×1231).

### Triage notes

This is by design today. In the Interconnection Diagram:
- an `in` port goes on top and an `out` port on the bottom;
- a port with no direction faces the other end of its wire, but with a strong bias toward top/bottom, because layers run top to bottom;
- an unwired port goes on the bottom.

Bike radar ports carry items in both directions, so none has a direction and almost all land on top or bottom.

Changing it is a layout policy decision, so it needs a short grilling before it's agent-ready:
- Should a port with items in both directions get a direction from its items at all?
- Does the in-top/out-bottom rule stay for directed ports, or do ports simply face their peer?
- Should the layout run left-to-right for Interconnection Diagrams instead, as many SysML tools draw an internal block diagram?
- What about unwired ports?
- How does the Standard Notation constrain this, if at all? (The notation reference PDF settles questions like this.)
